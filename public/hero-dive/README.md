# Assets del Hero "Laptop Dive" (`papis.app`)

Cuando generes tus archivos definitivos en **Higgsfield / Kling 3.0 / Veo**, simplemente suéltalos en esta carpeta (`public/hero-dive/`) con estos nombres exactos y el Hero los detectará automáticamente sin tocar código:

| Archivo | Formato | Qué es |
| :--- | :--- | :--- |
| `plate.webp` | 3:2 (2048×1360) | Foto principal tuya en estudio sosteniendo el portátil abierto (sin texto). |
| `cut.png` | PNG transparente 3:2 (mismo encuadre que `plate.webp`) | Tu recorte exacto para que el wordmark gigante `PAPIS.APP` pase por detrás de tu cabeza. |
| `case-plate.webp` | 3:2 (2048×1360) | El mismo portátil centrado y de frente con pantalla negra (sin persona). |
| `trans.mp4` | MP4 16:9 (~5s, sin audio) | Transición Kling 3.0 / Veo desde `plate` hasta `case-plate`. |
| `case-1.mp4` | MP4 16:9 (mudo, bucle) | Vídeo demo del Caso 1 (Web & SEO/GEO). |
| `case-2.mp4` | MP4 16:9 (mudo, bucle) | Vídeo demo del Caso 2 (Software a Medida ERP/CRM). |
| `case-3.mp4` | MP4 16:9 (mudo, bucle) | Vídeo demo del Caso 3 (Servicio Técnico & Formación). |

Mientras no existan estos archivos, el Hero funciona automáticamente con tus fotografías optimizadas actuales y transición cinematográfica fluida.
